# Python Programming Assignment 2 (CO2)

This folder contains Python solutions for all seven questions in the assignment brief.

## Files

- `Q1/subsidy_decision.py` — decisions with many boundaries
- `Q2/otp_loop.py` — while/for loops, break/continue/pass and loop-else
- `Q3/vehicle_registration_validator.py` — normalise, validate and format vehicle numbers
- `Q4/string_building_benchmark.py` — repeated `+=` vs `join()` timing experiment
- `Q5/canteen_order.py` — default-parameter bug and scope explanation
- `Q6/stair_climb_recursion.py` — recursive steps counting and memoisation
- `Q7/design_redesign.py` — diagnosis and redesign of a repeated-work problem

## Run each task

```bash
python Q1/subsidy_decision.py
python Q2/otp_loop.py
python Q3/vehicle_registration_validator.py
python Q4/string_building_benchmark.py
python Q5/canteen_order.py
python Q6/stair_climb_recursion.py
python Q7/design_redesign.py
```

## Notes

- The programs use only the Python standard library.
- The code was written to match the assignment requirements, including the stated `TODO` tasks and the evidence-based analysis expected in the report.
- Output varies slightly depending on the machine, especially timing values in Q4 and Q7.
